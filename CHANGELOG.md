# Changelog

## 0.1.0

Initial geometric diffusion–reaction library: checked nodal fields, harmonic-face stencils, nonzero Dirichlet lifting, Jacobi and symmetric Gauss–Seidel, full weighting/bilinear transfers, cached bounded coarse Cholesky, rediscretized V/W cycles, verified-residual solves, fixed V-cycle PCG and plain CG comparison, FMG initialization, conservative fluxes, interior COO/vector integration, manufactured equations, rectangular Poisson editing, strict bounded field JSON and CSV. Three runnable downstream workflows and an independent 12-grid differential harness accompany the package. Four-target CI is the release gate; see actual CI status for a particular commit.
